description: "Scientific data may be stored and managed in one platform while specialized analysis tools and workflows are available in another. This demonstrator shows how NOMAD can connect to the open-source data analysis platform Galaxy within the emerging EOSC federation, allowing data stored in NOMAD to be sent to an external analysis workflow and the results returned to NOMAD. Using XPS peak finding as an example, a NOMAD Action transfers an XPS dataset to Galaxy, launches a dedicated workflow, retrieves the processed result, and reimports it into the original NOMAD upload."
