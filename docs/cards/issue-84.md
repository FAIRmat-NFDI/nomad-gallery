description: "Experimental data are generated across facilities using different formats, catalogues, and terminology, making it difficult to discover and reuse data consistently. This demonstrator connects data sources through shared semantic concepts and standardized representations in NOMAD. Using X-ray absorption spectroscopy (XAS) data from ESRF and BESSY II as an example, it shows how data can be discovered across facilities, brought into a common representation, and processed with shared data analysis workflows."
